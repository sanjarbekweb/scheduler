Questions about the workspace

How do I enter all my classes?

Open Teaching plan and choose Add classes. The setup form offers missing class names from 1A through 11B. Review the sizes and shifts before saving.

Can a subject have several teachers?

Yes. Use subject teaching teams to mark qualified teachers, then assign the appropriate teacher to each class. Split lessons use two separate teacher assignments.

Which import formats work?

Project JSON and structured teaching-plan CSV are supported. Arbitrary Excel sheets and PDFs require conversion before import.

What happens when I move a lesson?

The move editor shows the chosen time and rooms. Applying it locks the choice and attempts to repair the remaining timetable. A failed manual repair leaves the saved timetable unchanged.

What does a failed search mean?

The result distinguishes an impossible set of conditions from a timeout. Neither result is presented as a completed timetable.

Does it support half-hour weekly allocations?

The current model uses integer weekly sessions. Alternating-week allocations are not implemented yet.

Where is my data stored?

The application stores its database on this computer. Export project JSON for an input backup and save versions to preserve timetables.
